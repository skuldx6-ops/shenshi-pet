# 申时桌宠

蓝色闹钟桌宠，面向 macOS 与 Windows。与原 macOS 菜单栏版「申时」是两个独立项目。

## 当前功能

- 透明、置顶、可拖动的桌宠窗口（角色显示约 148 × 160 像素）；位置记忆；托盘可恢复隐藏的桌宠。
- 待机时角色站在原地轻微缩放呼吸；闲置两分钟后走到最近的屏幕侧边、露出约半身，有提醒或拖动时完整出现。提醒时角色播放对应的 WebP 动作，结束后恢复站姿。
- 无配图文字气泡居中显示在桌宠头顶；靠近屏幕上缘时移到下方，拖动桌宠时跟随。气泡仅保留原版橙色提示和主文案两行，使用普通圆角；同时触发的提醒最多展示五条，竖向排列，后续提醒排队。角色播放最后一条可见提醒的动作。
- 护眼（默认 40 分钟）、饮水（默认 60 分钟）、午饭（每天本地时间 11:30）和打卡（每天 09:00、18:00）。护眼气泡显示 20 秒倒计时，饮水 20 秒后关闭，午饭 30 分钟后关闭。
- 自定义提醒：单次、每天、每周、每月；支持提前提醒、暂停、编辑和删除（最多 10 条）。
- 专注模式暂停定时提醒，退出后重新开始间隔计时。午饭提醒只有固定时间和提示文案，没有随机选餐功能。
- 正式应用首次启动时注册一次登录后自动启动；默认提醒设置窗口提供开机自启动开关。登录项绑定应用路径，请先将应用放在准备长期使用的位置。
- 点击桌宠后的菜单提供默认提醒、自定义提醒、专注模式、隐藏桌宠四项；自定义侧栏直接显示事项和下次提醒时间。默认与自定义提醒分别使用独立设置窗口。
- 保留原版五个 WebP 提醒动图。应用图标使用原版 `AppIcon.png`；状态栏图标使用另提供的透明底图片。素材源文件和三视图见 `design/character`。

应用须处于运行状态，定时提醒才会出现。睡眠后恢复时会按有限时间窗口补发近期提醒，不会集中弹出一整天的旧提醒。数据保存在本机应用 WebView 存储中。

## 项目结构

```text
design/character/       三视图与角色设计参考
src/assets/             桌宠和五个原版提醒动图
src/pet/                桌宠交互、拖动、位置记忆
src/reminders/          定时规则与跟随气泡
src/settings/           提醒及专注设置
src/shared/             多窗口定位
src-tauri/              Mac/Windows 原生窗口、托盘和打包
tests/                  定时规则测试
.github/workflows/      双平台构建
```

## 开发与构建

需要 Node.js 22、Rust 稳定版，以及 [Tauri 的平台依赖](https://v2.tauri.app/start/prerequisites/)。

```bash
npm ci
npm test
npm run tauri dev
npm run tauri build
```

GitHub Actions 在 Mac 与 Windows 分别构建安装包。未签名的 Mac 安装包可能受到 Gatekeeper 提示；正式分发前需配置 Apple 签名与公证。Windows 透明窗口和虚拟桌面行为仍需 Windows 实机验收。

开发采用一套跨平台代码：先在 Mac 上确认桌宠动作和气泡体验，每次提交都构建 Mac 与 Windows；Mac 交互稳定后再做 Windows 实机验收。喝水和自定义提醒目前沿用原版动图作为占位，后续可逐个替换动作素材，不影响提醒规则。

## 素材说明

原版 WebP 动图与应用图标来自现有「申时」项目，状态栏透明图由用户提供。三视图和透明待机稿由内置图像生成工具依据原版角色与用户参考图制作。待机稿边缘仍有少量生成碎点，正式发布前需清理。
